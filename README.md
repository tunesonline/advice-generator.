# Advice Generator App

A beginner-friendly Advice Generator built with HTML, CSS, and JavaScript.

## Features
- Loads advice when the page opens.
- Gets new advice when the dice button is clicked.
- Updates the advice number and advice text together.
- Shows loading and error messages.
- Disables the button while a request is in progress.
- Uses `textContent` to display API data safely.
- Responsive layout for desktop and mobile.

## Run locally
1. Keep `index.html`, `style.css`, and `script.js` in the same folder.
2. Open the folder in VS Code.
3. Open `index.html` in a browser. For the best testing experience, use the VS Code Live Server extension.

## API
`https://api.adviceslip.com/advice`
